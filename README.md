# Y700 G4 触控优化 + 480Hz 固件整合版（HyperOS 3.0）

## 项目简介
本模块将以下两位酷安大佬的成果整合，适用于 **联想拯救者 Y700 四代刷入 HyperOS 3.0** 的设备：
- **触控优化**：酷安 [@骏冲冲](https://www.coolapk.com/u/骏冲冲) 的触控模块，提升采样率、降低延迟。
- **480Hz 固件**：酷安 [@微微薇](https://www.coolapk.com/u/微微薇) 的 Y700 五代触控固件挂载方法。

模块仅包含触控功能，无性能调度，安全稳定。

## 功能特性
- 挂载 Y700 五代触控固件，实现 **480Hz 触控采样率**
- 解除系统帧率限制，支持最高 **165Hz** 屏幕刷新率
- 自动监测刷新率变化，**全刷新率下保持 480Hz 采样率**
- 降低触控延迟，优化游戏跟手性

## 使用说明
1. 下载模块 zip 包，通过 **Magisk** 或 **KernelSU** 刷入。
2. 重启设备。
3. （可选）修改 `/data/adb/modules/touch_y700g4_hyperos_480hz/config` 中的 `fps` 值：`auto` / `120` / `144` / `165`。
4. 验证采样率：触摸屏幕时执行 `getevent -r /dev/input/event5`，报点间隔约 **2.08ms** 即 480Hz。

## 注意事项
- 刷入前请备份原触控固件。
- 480Hz 会增加功耗与发热，请留意设备温度。
- 若触控异常，可在管理器中卸载模块恢复。
